# AIでのデザインがうんとよくなる、たった1つのコツ ── 部品の「名前」が分かる図鑑を作りました

AIに画面やホームページを作ってもらうとき、こんなふうに頼んでいませんか。

「上の帯を、もう少しおしゃれにして」
「ボタンを押したら出てくる窓、あれをもっと分かりやすく」

なんとなく直してはくれるけれど、思っていたのと違う。何度言い直しても近づかない。

それはAIの力不足ではありません。**部品の名前を知らないこと**が原因です。

## 「出てくる窓」には、少なくとも4つの名前がある

「上の帯」は、正しくは**ヘッダー**と呼びます。

「出てくる窓」はもっと複雑です。

- 画面の真ん中に出て、後ろが暗くなる → **モーダル**
- 「本当に削除しますか？」と聞いてくる → **ダイアログ**
- 画面の横からスッと出てくる → **ドロワー**
- 画面の下からせり上がってくる → **ボトムシート**

名前が違えば、AIが作る物もまったく違います。「窓」と言われたAIは、この中のどれかを当てずっぽうで選ぶしかありません。

## 同じAIに、2通りで頼んでみました

試しに、カフェの予約画面を同じAIに2通りで頼んでみました。

1つ目は、名前を知らないつもりで、

> 上に帯があって、今いくつめの手順か分かるようにして。名前と人数と受け取り方（店内・持ち帰り・配達）を入れられて、禁煙席がいいかどうかと、前の日にお知らせするかどうかも選べるようにして。最後に進むボタン


2つ目は、同じ内容を部品の名前で、

> 上にヘッダー、その下に**ステップ表示**（入力→確認→完了、今は入力）。名前はテキストフィールド、人数は**セレクトボックス**、受け取り方は**ラジオボタン**、禁煙席の希望は**チェックボックス**、前日のお知らせはトグルスイッチ。最後に『予約内容を確認する』のボタン


画像：docs/images/compare.png

1つ目では、人数は数字を打ち込む欄、受け取り方は横並びのボタン、禁煙席はスイッチになりました。手順の中身も「日時→内容入力→確認」と勝手に決められました。

2つ目は、頼んだとおりの画面が出てきました。言い直しはゼロです。

## そこで、部品の名前が分かる「図鑑」を作りました

**UI部品図鑑**
https://mashiharalab.dev/ui-parts-zukan/

見本の画面に、設計図のように線を引いて名前を書き込んだサイトです。無料で、登録もいりません。

画像：docs/images/drawing.png

ヘッダー、モーダル、ダイアログ、ラジオボタン、カルーセル……といった部品が53個。さらに「2列にする（カラム）」「スクロールしても付いてくる（sticky）」「スマホとパソコンで組み方を変える（レスポンシブ）」のような、画面の組み方のことばも15個。合わせて68個の名前が分かります。

## 使い方は3つだけ

### 1. 気になる部品を押す

図面の部品を押すと、名前と意味、どんなときに使うか、実際に動く見本が出てきます。

### 2. 「頼み方の例」をコピーする

部品ごとに、そのままAIに貼れる頼み方の例を付けました。たとえばダイアログなら、

> 削除ボタンを押したら確認ダイアログを出して。「削除しますか？」と聞き、「キャンセル」と赤い「削除する」を並べて。

自分の作りたい物に合わせて、少し書き換えるだけで使えます。

画像：docs/images/entry-dialog.png

### 3. まぎらわしい名前は「見分け方」で確かめる

似ていて取り違えやすい名前は、1行で見分けられるようにしました。

- **トーストとアラート**：数秒で勝手に消えるのがトースト、読むまで残るのがアラート
- **チェックボックス・ラジオボタン・トグルスイッチ**：いくつでも選べる四角、1つだけ選ぶ丸、押した瞬間に効くオン・オフ
- **カルーセルとスライダー**：写真を横に送って見せるのがカルーセル、つまみを動かして値を選ぶのがスライダー

画像：docs/images/confusions.png

使いたい部品をいくつか選ぶと、名前と意味をまとめた文にして、ChatGPT や Claude にまとめて渡すこともできます。

## 名前を1つ覚えるだけで、変わる

デザインの勉強をしたことがなくても大丈夫です。むしろ、そういう人ほど効果があります。

全部を覚える必要はありません。AIに伝わらなくてもどかしいと感じたときに図鑑を開いて、その部品の名前を1つ調べる。それだけで、AIの出す画面が見違えます。

「名前を知っていれば、AIに頼める」という考え方は、大滝昇平さんの Motion Prompt（動きの名前のライブラリ）から学びました。ふわっと出る、スッと消えるといった「動き」の名前は、そちらで調べられます。
https://showheyohtaki.github.io/motion-prompt/
