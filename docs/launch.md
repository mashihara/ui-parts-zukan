# 公開と告知

## 公開の残り作業

1. GitHub にリポジトリを作って push する
2. 公開先を決めてビルドする
   - Vercel: そのまま `npm run build`（出力は `out/`）。`SITE_URL` に公開URLを入れる
   - GitHub Pages: `NEXT_PUBLIC_BASE_PATH=/<リポジトリ名> SITE_URL=https://<ユーザー名>.github.io/<リポジトリ名> npm run build`
3. 公開URLを下の記事の `{URL}` に入れる。スキルの導入コマンド（`npx skills add <ユーザー名>/<リポジトリ名>`）もリポジトリ名が決まってから書く
4. `web-seo-setup` スキルで Search Console に登録する

## X の記事（長文）の下書き

### タイトル

このサイトがあれば、AIでのデザインがうんとよくなる ── UI部品の「名前」が分かる『UIつまみ』を作りました

### 本文

AIに画面を作ってもらうとき、こんな指示をしていませんか。

「上の帯をもう少しおしゃれに」
「ボタンを押したら出てくる窓、あれをもっとやさしい感じに」

伝わらないのは、AIの力不足ではありません。**部品の名前を知らないこと**が原因です。

「上の帯」はヘッダー。「出てくる窓」は、後ろを暗くして中央に出るならモーダル、「本当に削除しますか？」と聞くならダイアログ、横から出るならドロワー、下からならボトムシート。名前が違えば、AIが作る物もまったく違います。

そこで、UI部品の名前が分かり、見た目をつまみで決めて、そのままAIへの指示文にできるサイトを作りました。

**UIつまみ**
{URL}

---

#### ① 画面を押すと、名前が分かる

見本の画面の部品にカーソルを乗せると、「ヘッダー」「パンくずリスト」「ラジオボタン」「トグルスイッチ」と名前の札が出ます。押すと、その部品の説明と使いどころ、調整の画面に進みます。

ヘッダー・フッター・モーダル・ダイアログ・ツールチップ・トースト・チップ・スケルトンなど、43個の名前を入れました。

（画像：「名前を全部出す」にした画面の地図）

#### ② まぎらわしい名前の見分け方

AIへの指示で特に取り違えやすい名前は、1行で見分けられるようにしました。

- ツールチップとポップオーバー：乗せるだけで出て読むだけならツールチップ、押して開いて中も押せるならポップオーバー
- トーストとアラート：数秒で勝手に消えるのがトースト、読むまで残るのがアラート
- チェックボックス・ラジオボタン・トグルスイッチ：いくつでも選べる四角、1つだけ選ぶ丸、押した瞬間に効くオン・オフ

#### ③ 見た目は「言葉のつまみ」で決める

「角の丸さ：角ばる／少し／やや丸い／丸い／まんまる」「ゆとり：ぎっしり〜たっぷり」「影：平ら〜浮いている」のように、専門用語を知らなくても選べるつまみにしました。動かすと見本がその場で変わります。

迷ったら「やさしい」「きりっと」「元気」「高級感」の言葉1つで、全部のつまみがまとめて動きます。

（画像：同じ画面を「やさしい」と「きりっと」で並べた比較）

#### ④ そのままAIへの指示文に

決めた見た目は、部品の正式名と数値（px・色・秒・CSS変数）の入った指示文になります。Claude・ChatGPT・Codex・Cursor に貼って「このデザインでログイン画面を作って」と添えるだけです。

調整した状態はURLにも入るので、リンクを渡すだけでも伝わります。AI向けに llms.txt も用意しています。

---

動きの名前（モーションの名前）は、大滝昇平さんの Motion Prompt で調べられます。「名前を知っていれば、AIに頼める」という考え方はそこから学びました。UIつまみは、その考え方をUI部品の見た目に広げたものです。

デザインの勉強をしていない人ほど、名前を1つ覚えるだけでAIの出す画面が見違えます。ぜひ触ってみてください。

### 添える画像の候補

1. 「名前を全部出す」にした画面の地図（PC幅）。札が並んだ1枚が一番伝わる
2. 「やさしい」と「きりっと」で同じ画面を並べた比較
3. 指示文の画面（数値とCSS変数が入っているのが分かる部分）
4. あいまいな指示とUIつまみの指示文で、同じAIに作らせた画面の比較（作れば最も強い証拠になる）
