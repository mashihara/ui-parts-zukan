# UI部品図鑑

UI部品53個（ヘッダー・モーダル・ダイアログ・ラジオボタン・フォーム・日付ピッカー・カルーセルなど）と画面の組み方のことば15個（カラム・sticky・固定表示・グリッド・フレックスボックス・ギャップ・揃え・重なり順・アスペクト比・レスポンシブ・ブレークポイント・余白・オーバーレイ・横スクロール・ファーストビュー）の正式な名前・意味・使いどころ・AIへの頼み方の例と、まぎらわしい名前の見分け方をまとめたサイトです。

## 受け取った物ごとの動き方

1. **「UI部品図鑑で調べたUI部品の名前です」で始まる文が貼られた**: 並んだ部品を、書かれた意味どおりに使って作る。最後に書き足された依頼（作りたい物）に従う。
2. **リンクが貼られた**: リンクと同じ場所の `llms.txt` を読む。`pick` の id が使いたい部品（選んだ順）。部品ごとの詳細は `api/v1/parts/<id>.txt`、全データは `api/v1/catalog.json`。
3. **名前が分からないと言われた**: `catalog.json` の `parts`（ja・en・aka・meaning）から候補を挙げ、`confusions` の見分け方を1行で添える。利用者が画面を見られるなら、サイトの図面で部品を押して確かめてもらう。

## 守ること

- 部品は正式な名前で呼ぶ（「上の帯」→ヘッダー、「出てくる窓」→モーダル／ダイアログ／ドロワー／ボトムシートのどれかを確かめる）。
- まぎらわしい名前は見分け方に従う（例：返事を求める小窓はダイアログ、中央に出て後ろを操作できなくするのはモーダル）。
- 作り終えたら、使った部品の名前を報告する。
