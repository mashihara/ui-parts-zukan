# UIつまみ

UI部品（ヘッダー・モーダル・ダイアログ・ラジオボタンなど43個）の正式な名前と、見た目のつまみ（色・角の丸さ・余白・影・枠線・文字・動き）をまとめたサイトです。利用者は画面で調整し、名前と数値の入った指示文かリンクを渡してきます。

## 受け取った物ごとの動き方

1. **指示文が貼られた**（「UIつまみで調整したUIのデザインです」で始まる）: 書かれた名前と数値をそのまま使って作る。文言・中身・画像だけを作っている物に合わせる。プロジェクトに既存のUIライブラリ（Tailwind・shadcn/ui・MUI・Flutter など）があれば、その仕組みの中で同じ見た目にする。
2. **リンクが貼られた**: リンクと同じ場所の `llms.txt` を読み、「URLの書き方」に従ってクエリを読み解く。部品ごとの詳細は `api/v1/parts/<id>.txt`、全データは `api/v1/catalog.json`。
   - 全体のつまみは `キー=値`（既定値なら省略）。`pick` は使う部品の id（選んだ順）。部品のつまみは `部品id=キー:値;キー:値`。
3. **名前が分からないと言われた**: `catalog.json` の `parts`（ja・en・aka・meaning）と `confusions` から候補を挙げ、まぎらわしい名前との違いを1行で添える。利用者が画面を見られるなら、サイトの「画面の地図」で部品を押して確かめてもらう。

## 守ること

- 数値（px・色・秒・イージング）を勝手に丸めたり作り替えたりしない。分からない値は推測せず、リンクか指示文を求める。
- 部品は正式な名前で呼ぶ（「上の帯」→ヘッダー、「出てくる窓」→モーダル／ダイアログ／ドロワー／ボトムシートのどれかを確かめる）。
- `prefers-reduced-motion` が有効なら動きを止める。アイコンだけのボタンには aria-label を付ける。
- 作り終えたら、使った部品の名前と、指示から変えた点を報告する。
